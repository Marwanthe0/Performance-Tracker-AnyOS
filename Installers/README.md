# PC Performance Tracker - 1-Click Installers

Welcome to PC Performance Tracker!

Choose your operating system below:

## 🪟 Windows (10 / 11)
- **Fastest Option**: Run `INSTALL_WINDOWS.bat` in the root folder, or go to `Windows/` and run `Install-Windows.bat`.
- **Standalone No-Install**: Run `Windows/PerformanceTracker.exe` directly.

## 🐧 Linux / Ubuntu
- **Debian / Ubuntu**: Run `sudo apt install ./Linux/ubuntu-performance-track_1.0.0_all.deb`
- **Any Linux**: Run `bash Linux/ubuntu-performance-track-installer.run` (no root required)
- **1-Click**: Run `bash ../INSTALL_LINUX.sh`

## 🍎 macOS
- **1-Click**: Run `bash ../INSTALL_MACOS.sh` or extract `macOS/PerformanceTracker-macOS.zip` to `/Applications`.
